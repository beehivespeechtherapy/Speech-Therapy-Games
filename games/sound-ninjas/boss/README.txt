Boss sprite (PNG or SVG)
========================
The game loads whatever file `boss.image` points to in `config.json`
(default: `boss/samurai_boss.png`).

Use a **real** PNG (binary) with a `.png` name, or real SVG text with a `.svg`
name. If the extension does not match the file bytes, the boss picture may not
show in the game (you might only see the emoji fallback).

After replacing the file, commit and push so GitHub Pages updates.

Homework sheet generator

Start this tool from Finder: double-click Homework Sheet Generator.command in the tools folder (do not open this index.html file directly — pictures will not load). Enter the two sounds you are comparing and the word position (Initial / Medial / Final). Paste exactly ten minimal pairs, one per line, with a slash between words (e.g. think/sink). Choose a picture folder inside word-images if your images live in a set folder. Print / Save PDF produces page 1 (instruction + word table) and page 2 (pictures).

Only images inside the folder you pick are used. Sets are split into Initial, Medial, and Final — the same word (e.g. van) may only exist in one of those; if pictures are missing, try V:B Minimal Pairs - Initial or All folders.

These appear in the printed title and as column headings in the word table.

Used in the instruction page title (e.g. “Minimal Pairs - Initial (words)”).

If filled, this appears as a second line under the main title on the instruction page.
